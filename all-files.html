# Harshit Kumar Sinha — Digital Brand Portfolio

An elite, high-performance personal brand web application for **Harshit Kumar Sinha**, Business Intelligence, AI Automation, and Data Analytics Specialist.

Built using Next.js 15 (App Router), TypeScript, Tailwind CSS, Framer Motion, Apache ECharts, `cmdk`, and Vercel AI SDK.

![Portfolio Preview](./public/og-image.png)

## 🌟 Key Highlights & Design Systems

- **Apple-Grade Whitespace & Layout:** Spacing rhythm tailored for maximum focus and visual legibility.
- **Stripe Dark Glassmorphism:** Micro-gradients, glowing ambient backdrops, and refined slate color palettes.
- **Linear Animation Curves:** Smooth spring dynamics and subtle entrance transitions via Framer Motion.

## 🚀 Quick Start Guide

### 1. Clone & Install Dependencies
```bash
git clone https://github.com/harshit-sinha/Portfolio.git
cd Portfolio
npm install
```

### 2. Configure Environment Variables
Create `.env.local` in the root directory:
```env
OPENAI_API_KEY=your_openai_api_key_here
NEXT_PUBLIC_SITE_URL=https://harshitsinha.dev
```

### 3. Launch Local Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for Production
```bash
npm run build
npm run start
```

export const runtime = 'edge';

export async function POST(req: Request) {
  const { messages } = await req.json();

  const apiKey = process.env.GROQ_API_KEY ?? process.env.OPENAI_API_KEY;
  if (!apiKey) {
    return new Response(JSON.stringify({ error: 'Missing GROQ_API_KEY on server.' }), {
      status: 500,
      headers: { 'Content-Type': 'application/json' },
    });
  }

  const upstream = await fetch('https://api.groq.com/openai/v1/chat/completions', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${apiKey}`,
    },
    body: JSON.stringify({
      model: 'llama-3.3-70b-versatile',
      stream: true,
      max_tokens: 1024,
      temperature: 0.7,
      messages,
    }),
  });

  if (!upstream.ok || !upstream.body) {
    return new Response(JSON.stringify({ error: 'Upstream AI stream failed.' }), {
      status: upstream.status,
      headers: { 'Content-Type': 'application/json' },
    });
  }

  return new Response(upstream.body, {
    status: 200,
    headers: {
